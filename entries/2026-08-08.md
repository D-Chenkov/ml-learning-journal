## Module 2 - Specialized Vision (interpretability + diffusion)

**Learned:**
- Feature map: output of a conv layer (one map per filter; stacked = the output volume).
- Receptive field: the region of the INPUT image that can influence a given unit; deeper units see larger regions. Effective RF (Luo et al.) is smaller than theoretical and roughly Gaussian (center pixels dominate). Grow the RF with depth, pooling/strided convs, larger kernels, or dilated (atrous) convs.
- Saliency maps (Simonyan): gradient of the pre-softmax class score w.r.t. input pixels; shows which pixels the prediction is most sensitive to. Noisy; only local sensitivity.
- Class Activation Maps (CAM): heatmap of where the network looked = weighted sum of last conv feature maps by the class's final-layer weights. Requires a Global Average Pooling layer into the final linear/softmax (else modify + retrain). Grad-CAM generalizes it via gradients, works on any CNN with no retraining.
- Diffusion: forward = add Gaussian noise on a fixed schedule (no learning); reverse = a learned U-Net that iteratively denoises. Training is single-step: add known noise e at random timestep t, U-Net predicts e_hat, loss = MSE(e, e_hat). Generation = start from noise and run reverse steps.
- Stable Diffusion = latent diffusion: VAE encoder compresses image to a small latent, diffusion runs in latent space, VAE decoder reconstructs. Much cheaper than pixel space.
- Classifier-free guidance (CFG): guided = uncond + scale * (cond - uncond). Scale = how hard to push toward the prompt. High = adheres but uncanny/over-sharpened; low = creative but may drift. Negative prompts fill the unconditioned slot.
- Interpretability value (Clever Hans): models can be right for the wrong reasons (wolf classified by snow). Saliency/CAM catch spurious shortcuts before deployment.

## Module 3 - Specialized NLP (transformers)

**Learned:**
- Why attention: RNN seq2seq squeezed the whole source into one fixed context vector (a bottleneck). Attention lets the decoder look back at all encoder states and weight the relevant ones. "Attention Is All You Need" then dropped recurrence entirely - fully attention-based, so it parallelizes across the sequence (RNNs are sequential).
- Self-attention: every token attends to every token in the SAME sequence. From each token's embedding, learned projections produce a Query, Key, and Value. Scaled dot-product attention: softmax(Q K^T / sqrt(d_k)) V. The 1/sqrt(d_k) scaling keeps dot products from getting huge and saturating the softmax.
- Multi-head attention: run attention h times in parallel with different learned projections, then concatenate. Lets the model attend to different relationships / representation subspaces at once.
- Positional encoding: with no recurrence there is no built-in order, so add positional information (sinusoidal or learned) to the embeddings so the model knows token order.
- Encoder block: multi-head self-attention + a position-wise feed-forward network, each wrapped in a residual connection + layer normalization. Stack N of them. (Encoder was also used for text classification: encoder -> pool -> classification head.)
- Decoder block: MASKED (causal) self-attention so a position cannot peek at future tokens + cross-attention over the encoder outputs (Query from the decoder, Key/Value from the encoder) + FFN, all with residual + layernorm.
- Encoder-decoder: encoder reads the source sequence, decoder generates the target autoregressively while cross-attending to the encoder output. This is the setup for the module's assignment, a translation system.
