## What was reviewed and learned

### 1. Tuning family and task taxonomy
- Information Extraction: Task of pulling structured key-values (policy number, date of loss, damage type, estimated cost) from unstructured customer emails.
- Prompt design (few-shot): Changes 0 weights. Delivers instructions, output schema, and in-context examples.
- PEFT / LoRA (adapter tuning): Base model is completely frozen. Injects and trains a small set of added low-rank adapter matrices into attention and feed-forward layers. It is not transfer learning (not unfreezing or retraining the classification head), and adapter weights are trainable parameters optimized via backpropagation, not hyperparameters.
- Full fine-tuning: Updates 100% of all model parameters on labeled datasets.

### 2. 4-level GCP agent build spectrum
- Level 4 Solutions (zero code): Gemini Enterprise App (internal workplace search, ticket updates, no-code Agent Designer) and Gemini Enterprise for CX (customer-facing retail and support).
- Level 3 Agent Platform and ADK: Agent Studio is a low-code visual interface for prompt engineering, tool configuration, and reasoning loops. Agent Development Kit (ADK) is the pro-code Python framework for multi-agent graphs and sub-agent delegation.
- Level 2 Orchestration frameworks: Open-source graph frameworks like LangGraph, LlamaIndex Workflows, and CrewAI.
- Level 1 DIY / raw API: Direct function calling in code with custom loops handling Gemini API payloads.
- Boundary: Vertex AI Model Garden is a foundation model catalog (Google's enterprise model repository), not an agent builder.

### 3. RAG mechanics and RAGAS metrics
- Conversational condense step: FAISS and BM25 retrievers are stateless. When Turn 2 has ambiguous pronouns ("How does that compare to the previous quarter?"), the condense step rewrites it into a standalone query. This is a retrieval correctness fix, not a token or cost saving optimization.
- RAGAS metric split: context_recall and context_precision = retrieval; faithfulness and answer_relevancy = generation.
- Coverage math: Total text budget is k * chunk_size. Halving chunk size at fixed k cuts total retrieved text in half, directly hurting recall if the target context exceeds that capacity.

### 4. Drift foundations and GCP Vertex monitoring
- Covariate shift (data drift): P(X) changes while P(Y|X) remains constant. Feature distribution shifts (e.g., user age demographic grows older), but feature-to-label mapping holds.
- Concept drift: P(Y|X) changes. The relationship between inputs and targets changes (e.g., definitions of spam or fraud shift due to adversary adaptation or inflation).
- Reference dataset: Baseline curated training or validation distribution, or a verified golden historical serving window.
- Vertex AI Model Monitoring skew vs drift:
  - Training-Serving Skew (Feature Skew): Compares live production serving features against baseline training data.
  - Prediction Drift (Serving Drift): Compares live serving data across two consecutive production time windows (e.g., current 48h vs previous 48h).

### 5. Decoding parameters
- Order of operations: Logits scaled by temperature then softmax -> truncate via top-k (fixed count) and/or top-p (cumulative mass) -> sample next token.
- top-p (nucleus sampling): Smallest set of top tokens whose cumulative probability mass sums to >= p. The set size is dynamic because it contracts when the model is confident and expands when the distribution is flat.
- Temperature = 0: Softmax collapses into a deterministic argmax where the top token has probability 1.0, making top-k and top-p irrelevant.

### 6. Prometheus metric types and drift tests
- Metric types: Counter = monotonically increasing count (total prediction requests); Gauge = value that fluctuates up and down (drift score, PSI); Histogram = samples into configurable buckets to calculate percentiles (p50, p90, p99 latency).
- Statistical tests: Numerical features with large sample sizes use Wasserstein distance, Kolmogorov-Smirnov (K-S) test, or binned PSI. Categorical features use Jensen-Shannon distance, Chi-squared test, or PSI.
