Finished the DeepLearning.AI LangChain course (ran it on the local Ollama stack: ChatOllama + gemma4:e4b, OllamaEmbeddings nomic-embed-text). Quizzed the concepts.

**Learned:**
- Memory: LLMs are STATELESS - each call is independent. Memory stores the conversation and re-injects it into the prompt every call (continuity is just re-sending history). BufferWindow (last k) and Summary (compress) exist because stuffing the whole history back in blows up context + cost.
- Prompt templates: reusable, parameterized prompts (variables, few-shot). Output parsers: two-way - they inject format_instructions INTO the prompt (steer the model to parseable output) AND parse + validate the response into a dict/Pydantic object.
- Chains: LLMChain = the atomic step (prompt + LLM + optional parser). SequentialChain = several LLMChains wired output->input (multi named in/out); SimpleSequentialChain = single-in/single-out linear pipe.
- RouterChain: an LLM classifies the query and dispatches it to the best specialized destination chain (its own prompt/model), with a default fallback chain. The soft/learned version of mixture-of-experts gating.
- RAG pipeline (document Q&A): load (PyPDFLoader) -> split (RecursiveCharacterTextSplitter, overlapping chunks) -> embed (each chunk -> vector) -> store (FAISS index) -> retrieve (embed the question, similarity search, top-k) -> generate (stuff retrieved chunks into the prompt, LLM answers grounded in them). Steps 1-4 once; 5-6 per query. RetrievalQA / ConversationalRetrievalChain (with memory).
- Retrieval chain types (how to COMBINE retrieved chunks through the LLM, not retrieval): stuff (all in one call; simplest; breaks past context window), map_reduce (LLM per chunk then combine; scales, more calls), refine (iterative, answer + next chunk; slow), map_rerank (per-chunk answer + confidence, take highest).
- Retrieval mechanism: per-CHUNK embeddings compared to the question embedding by cosine similarity; semantic (meaning) not keyword. Top-k nearest chunks returned.
- Agents: add a reasoning/decision LOOP (ReAct: reason -> act -> observe -> repeat) + tools. Control flow is dynamic (LLM chooses the path) vs a chain's fixed path. More capable but less predictable / harder to eval.
