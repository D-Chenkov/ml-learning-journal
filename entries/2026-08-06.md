# 2026-08-06 - PyTorch Course 3, Module 1 (Designing Custom Architectures)

Started Course 3 (the last course of the PyTorch set). Module 1: building custom nn.Module architectures, Siamese / similarity learning, and two landmark CNN designs (ResNet, DenseNet).

**Learned:**
- Custom architectures: subclass nn.Module, define __init__ (call super().__init__(), instantiate/register submodules so PyTorch tracks their params) and forward (the forward computation). Call model(x), not .forward(); backward is auto-derived.
- Siamese networks: twin subnetworks that SHARE weights. Both inputs go through the same backbone, producing embeddings in a common space, then you compare by distance/similarity. Weight sharing is what puts both embeddings in the same space.
- Similarity learning beats classification for open-set, few-shot problems (signature verification, face recognition): potentially millions of identities, few samples each, new ones constantly. A classifier needs fixed classes + retraining to add one; a Siamese model learns a general similarity metric, so enrolling someone new is just storing a reference embedding. Generalizes to identities never seen in training.
- Triplet loss: inputs are anchor, positive, negative. Objective is relative: d(anchor, negative) > d(anchor, positive) + margin. Loss = max(0, d(a,p) - d(a,n) + margin). Pull positive close, push negative far, but only up to the margin (no overshoot). Positive is never pushed away.
- ResNet skip connections: solve vanishing gradients and the degradation problem (deep plain nets get worse on training error). Block computes F(x) + x; the +x path has derivative 1 so gradient flows back unchanged (gradient highway). Also lets a block learn identity easily (drive F(x) -> 0).
- DenseNet: CONCATENATES instead of adding. Each layer receives the concatenated feature maps of all preceding layers and feeds its output to all later ones. Channels grow by the growth rate k. Gives strong feature reuse and fewer parameters than expected. (This was my red - ResNet adds, DenseNet concatenates.)
- Transition layers (DenseNet): between dense blocks, compress channels (1x1 conv, compression factor ~0.5) and downsample (2x2 average pooling) to keep channels/feature-map size and memory manageable.
- Visual search with embeddings: train the embedding net, precompute + store embeddings for the whole database offline, then at query time embed the query and return the top-K nearest by distance (use an approximate NN index like FAISS at scale). Negatives matter only in training; retrieval is pure nearest-neighbor.
- Siamese forward: call the SAME self.backbone on each input (e1 = backbone(x1); e2 = backbone(x2)). Do NOT make two separate backbones or weight sharing breaks.
