## Project #3 final results (1D-ResNet + augmentation, on the PC)

Test set (21,892 beats), early stop @ epoch 67:
- **macro-F1 0.914** (up from 0.715 shallow baseline), accuracy 0.986, weighted-F1 0.985.
- Per class (P/R/F1): N 0.989/0.997/0.993; S 0.919/0.759/0.832; V 0.971/0.957/0.964; F 0.840/0.747/0.791; Q 0.994/0.986/0.990.
- The two hard classes jumped hugely (S 0.345->0.832, F 0.458->0.791 F1).

Why it worked (and weighting didn't): residual depth raised the model's capacity ceiling (skip connections let the deeper net actually train), and augmentation added effective data/variety for the rare classes. Loss weighting only rebalances a FIXED model - it can't add capacity or data, so it shifted precision/recall but not macro-F1. (Term note to self: it's a ResNet / residual CNN, not an RNN.)

Honest limitation (in the model card): the Kaggle split is beat-level random, so the SAME patient's beats appear in train and test -> intra-patient leakage. The model can shortcut on a person's waveform signature instead of learning generalizable arrhythmia features, so 0.986 is optimistic vs a patient-wise (inter-patient / AAMI) split. Future work: redo with a patient-wise split for an honest generalization number.

## LangChain "Chat with Your Data" (RAG deep dive)

- MMR (Maximal Marginal Relevance) retrieval: plain top-k returns near-duplicate chunks; MMR balances relevance to the query against diversity from already-picked chunks (lambda), so you get varied-but-relevant context.
- Self-query retrieval: an LLM splits a natural-language query into a semantic search string + a structured METADATA filter (e.g. "RAG papers after 2022" -> search "RAG" + filter year>2022). Needs metadata on the docs; does what pure embeddings can't (hard constraints).
- Contextual compression: after retrieval, an LLM trims each chunk to only the query-relevant sentences and drops irrelevant chunks -> tighter, higher-signal context. Big win for a local model (small context window, slow inference); tradeoff is extra LLM calls.
- Retrieval mechanism recap: per-chunk embeddings vs the question embedding by cosine similarity; semantic not keyword.
