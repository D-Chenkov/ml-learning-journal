**Learned:**
- Text pipeline: tokenization (raw text to token strings) -> tensorization (map tokens to integer IDs, pad/truncate to uniform length, build attention mask) -> embeddings (IDs to dense vectors, shape [batch, seq_len, embed_dim]).
- Subword tokenization (BPE, WordPiece): solves out-of-vocabulary and caps vocabulary size. Any word decomposes into known pieces (down to characters), so rare/new/misspelled words avoid a lossy [UNK].
- Embeddings: nn.Embedding is a learnable lookup table of shape [vocab_size, embed_dim]; a token ID indexes a row. Meaning is learned, and the real testable property is relational geometry (king - man + woman ~= queen), not literally-labeled dimensions.
- nn.Embedding vs nn.EmbeddingBag: Embedding = lookup only (per-token vectors). EmbeddingBag = lookup + pooling (mean/sum/max) fused, returns one vector per sequence, more efficient, handles variable length via offsets (no padding/mask). Bag-of-embeddings classifier.
- Cosine similarity: angle between vectors (+1 same, 0 unrelated, -1 opposite). Preferred over Euclidean because it ignores magnitude and magnitude is often incidental (frequency); direction carries meaning.
- Fine-tuning BERT/DistilBERT: keep the pretrained encoder + embeddings, add a new classification head on the [CLS]/pooled output. Full fine-tuning (unfreeze whole encoder, small LR ~2e-5) is the common strong recipe; feature extraction (freeze encoder, train head) is the lighter option.
- DistilBERT: made by knowledge distillation (small student mimics large teacher's output probabilities). ~40% smaller, ~60% faster, keeps ~97% of performance. Trade-off: small accuracy drop for big size/speed win.
- Tokenizer and weights must come from the same checkpoint: IDs index embedding rows, so a mismatched vocab scrambles every lookup.
- t-SNE / PCA for visualization: PCA is linear (max-variance); t-SNE is nonlinear, preserves local neighborhoods only. Caveat: cluster sizes, gaps, and between-cluster distances in a t-SNE plot are NOT meaningful; it's stochastic and perplexity-sensitive.
