# 2026-08-07 - PyTorch Course 3, Module 2 (Specialized Vision: interpretability + diffusion)

Module 2 of Course 3. Two halves: CNN interpretability (feature maps, receptive fields, saliency, class activation maps) and generative vision (diffusion, Stable Diffusion). Both tie to backlog items - interpretability to the SHAP/LIME plan item, diffusion to the AI-image-detector idea.

**Learned:**
- Feature map: the output of a conv layer (one map per filter; stacked = the output volume, each value a filter's activation at a location).
- Receptive field: the region of the INPUT image that can influence a given unit's value. Deeper units see larger regions. The EFFECTIVE receptive field (Luo et al.) is smaller than the theoretical one and roughly Gaussian - center pixels dominate.
- Growing the receptive field: more depth, plus pooling / strided convs (downsampling), larger kernels, and dilated (atrous) convolutions (wider reach, no extra params, no resolution loss).
- Saliency maps (Simonyan): gradient of the pre-softmax class score with respect to input pixels; magnitude = which pixels the prediction is most sensitive to. Reduce across channels for a heatmap. Caveat: noisy, only local sensitivity (hence guided backprop / integrated gradients / Grad-CAM).
- Class Activation Maps (CAM, Zhou): heatmap of WHERE the network looked for a class = weighted sum of the last conv feature maps by that class's final-layer weights, upsampled. Requirement/limitation: needs a Global Average Pooling layer into the final linear/softmax, so other architectures must be modified and retrained. Grad-CAM fixes this by using gradients into the last conv layer - works on any CNN, no retraining.
- Diffusion: forward process adds Gaussian noise on a fixed schedule until pure noise (no learning); reverse process is a learned U-Net that iteratively denoises. Generation = start from random noise, run the reverse steps.
- Diffusion training objective: single-step. Take a clean image, pick a random timestep t, add known noise e; the U-Net (given the noisy image + t) predicts e_hat; loss = MSE(e, e_hat). Iterative denoising only happens at generation time.
- Stable Diffusion = latent diffusion: a pretrained VAE encoder compresses the image to a small latent, the whole diffusion U-Net runs in latent space, the VAE decoder reconstructs. Far cheaper than pixel-space diffusion - why it runs on consumer GPUs.
- Classifier-free guidance (CFG): at each step the model predicts conditioned (on prompt) and unconditioned (empty prompt) noise and extrapolates: guided = uncond + scale * (cond - uncond). Scale = how hard to push toward the prompt. Trade-off: high scale sticks to the prompt but looks over-sharpened / uncanny; lower scale gives creative liberty but may drift. Negative prompts plug into the unconditioned slot (push away from what you do not want).
- Interpretability value (Clever Hans): models can be right for the wrong reasons (wolf classified by snow background, not the animal). Saliency/CAM reveal the model looking at the wrong region so you catch spurious shortcuts before deployment. Extra relevant for biosignals, where latching onto a sensor artifact would be dangerous.
- AI-image detection is hard: every generator (and version) leaves different artifacts (no universal fingerprint), detectors overfit to specific generators, artifacts shrink as models improve, and post-processing scrubs the signals. Arms race - lean on rigorous per-generator eval + provenance (C2PA), not one magic classifier.
